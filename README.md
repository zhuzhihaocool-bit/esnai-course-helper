# 上海国家会计学院继续教育 · 课程助手

一个 Tampermonkey 用户脚本，用于 **ce.esnai.net**（上海国家会计学院远程教育网 · 天津资产评估师继续教育）的课程学习。

**它只做三件事**：读进度、学时达标后在新标签打开下一门、关闭旧播放标签。

> ⚠️ **本脚本不代学、不刷课、不伪造学时。** 学时全部来自你本人实际播放的时间。项目的目标只有一个：
> **把"守着看课"变成"挂着后台，去做别的事"**，而不是跳过学习过程。

---

## 为什么会有这个脚本

这个平台的学时计算方式很特殊，值得先说清楚，因为它决定了脚本能做什么、不能做什么：

| 事实 | 依据 |
|---|---|
| 学时按**真实流逝时间**累计，与视频播放位置无关 | 每 60 秒向 `updateTimeSeconds.do` 上报一次 `seconds=60`，返回 `已学习 N 分钟` |
| **倍速不增加学时** | 4 倍速播放时，上报值仍是 `seconds=60`；视频提前跑完，学时只走了 1/4 |
| 学时可能被**回扣** | 实测出现过 `232 分钟 → 229 分钟`，说明服务端有有效性校验 |
| 视频源是腾讯云点播 | `getVideoToken.do` 取 token + sign，埋点走 `v.qidian.qq.com` |

因此，**"加速刷完"在这个平台上没有意义**——省下的时间要以补播的形式还回去。真正能省的只有**注意力**：
让课程在后台按 1x 播放，播完自动换下一门，你不需要一直盯着。

## 功能

| 功能 | 说明 |
|---|---|
| 📋 课程清单读取 | 解析列表页表格，得到每门课的 `courseWareId` / `orderItemId` / 百分比 |
| ⟳ 列表页自动刷新 | 默认每 5 分钟刷新一次，让百分比保持最新（不刷新时页面是静态快照） |
| 🎯 学时达标即跳 | 列表页显示 100% 时，在新标签打开下一门 |
| 🗂 只保留一个播放标签 | 新标签打开成功后，旧标签自动关闭或变空白页，避免多标签同时解码 |
| ▶ 自动播放兜底 | 每秒尝试 `play()`；被策略拦截时给出明显的"点这里开始播放"按钮 |
| 🛡 学时保护 | 视频播完但列表页未满 100% 时**不跳转**，提示继续累计 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）
2. 安装脚本，任选其一：
   - 打开 `esnai-course-helper.user.js`，点 Raw → Tampermonkey 会弹出安装页
   - 下载后拖进浏览器窗口
   - 新建脚本，粘贴全文保存
3. 打开 `https://ce.esnai.net/cpvtianjin/study.do`，顶部出现蓝色横幅即成功

### 使用流程

```
保持两个标签页打开：
  ① 列表页 study.do   ← 总控台，别关，它会自己刷新
  ② 播放页            ← 点「现在就进这门」在新标签打开

之后不用管：
  学时满 100% → 新标签打开下一门 → 旧标签自动释放 → 循环
```

### 可选配置

在继续教育站点任意页面按 `F12` → Console：

```js
// 列表页刷新间隔（秒，默认 300，最小 15）
localStorage.setItem('sh-refresh', '300')

// 重置完成记录（脚本会重新扫描所有未满 100% 的课）
localStorage.removeItem('sh-done')

// 完全停用（不建面板、不跳转、不刷新）
localStorage.setItem('sh-auto', '0')
```

## 设计约束（重要）

这些"不做"是踩坑换来的，**请不要在 issue 里要求增加**：

| 不做 | 原因 |
|---|---|
| ✗ 写 `video.currentTime` 跳进度 | 流媒体 seek 到非关键帧 → **画面全黑，但时间继续走、字幕正常** |
| ✗ 写 `video.muted` / `volume` | 部分播放器 `volume=0` 会停掉解码 → 同样黑屏 |
| ✗ hook `fetch` / `XMLHttpRequest` | 视频分片被强行 `clone().text()` 读取 → 缓冲整个流、播放器卡死 |
| ✗ 创建 iframe 加载本站 | 脚本会在 iframe 内再次注入 → **无限递归加载，浏览器整机卡死** |
| ✗ 伪造 `seconds=60` 上报值 | 服务端有回扣机制（232→229）；且这属于向发证机构申报虚假学时 |
| ✗ 跳进度条 / 二段播放 / 秒播 | 同上，且极易被判为异常学习记录 |

脚本**只写一个播放器属性**：`playbackRate`（倍速）。这个操作可逆，不影响解码。

## 已知限制

| 限制 | 说明 |
|---|---|
| 仅适配天津站点 | `ce.esnai.net/cpvtianjin/`；其他地区页面结构不同，需改 `listUrl()` 与表格解析 |
| 依赖列表页做数据源 | 播放页的 `平台 %` 来自列表页缓存。列表页关掉后，百分比显示红色"列表页未开" |
| `window.close()` 受限 | 浏览器只允许脚本关闭自己 `window.open` 打开的标签；手动打开的标签只能变 `about:blank` |
| 自动播放可能被拦 | Chrome 对无用户手势的 `window.open` + `play()` 有限制，此时需手动点按钮 |
| 倍速对学时无效 | 见上文，这是平台机制，不是脚本缺陷 |
| 课程结构变化会失效 | 平台改版后表格解析可能失败，横幅会提示"没扫到课程表格" |
