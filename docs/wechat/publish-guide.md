# 公众号发布操作步骤

## 一、先打开复制页面

双击 `docs/wechat/article-copy.html`，浏览器里会打开一个排版好的页面：

```
┌─────────────────────────────────────┐
│ 使用方法（黄色提示条）                │
│ [复制全文] [复制为纯文本]             │
├─────────────────────────────────────┤
│                                     │
│  先说结论                            │
│  这个平台的学时，没法加速。           │
│  ...                                │
│                                     │
└─────────────────────────────────────┘
```

点 **「复制全文」**（蓝色按钮），它会把排版和文字一起复制到剪贴板。

## 二、粘贴到公众号

1. 登录 https://mp.weixin.qq.com
2. 左侧「内容与互动」→「图文消息」→「新的创作」→「写新图文」
3. **标题**填：

```
看完 60 学时继续教育，我写了个脚本
```

4. **作者**（可选）：填你的名字或笔名
5. **摘要**填：

```
花 60 小时盯着看继续教育视频，实在受不了。我抓包摸清了平台的计时逻辑，写了个脚本把这件事的注意力成本降到接近零。记录一下过程和结论。
```

6. **正文区点一下**，然后 `Ctrl + V` 粘贴

粘贴后检查：
- 标题层级是否正常（「先说结论」等应显示为大字）
- 列表有没有变成圆点
- 代码块是否保持等宽字体

## 三、处理表格和代码块

公众号编辑器对表格支持较差，手机上会挤。**建议把两个表格做成图片**：

| 要转成图片的 | 位置 |
|---|---|
| 倍速对照表（1x/4x 那两行） | 「抓包看到什么」之后 |
| 代码块（POST 请求那段） | 同上 |

做法：
1. 在浏览器里截取表格区域
2. 在正文里删除刚粘贴的表格
3. 光标定位到原位置 → 点编辑器工具栏的「图片」→ 上传截图

代码块如果不想截图，也可以保留——但把字号调小一点，避免手机上换行错乱。

## 四、上传配图

建议 3-4 张，插在对应位置：

| 序号 | 位置 | 内容 |
|---|---|---|
| 1 | 开头「先说结论」之前 | 课程列表页截图（横幅+待学门数） |
| 2 | 「中间踩的坑」 | 黑屏截图（画面全黑但时间在走） |
| 3 | 「最后怎么解决的」 | 播放页面板（进度+倍速） |

**截图前必须遮掉**：姓名、单位、订单号、身份证、头像。

## 五、设置「阅读原文」

正文编辑页**最下方**，找到「原文链接」：

```
https://github.com/zhuzhihaocool-bit/esnai-course-helper
```

这是公众号里**唯一**可以点击跳转外部链接的位置。

## 六、发布设置

| 项目 | 建议 |
|---|---|
| 封面图 | 用课程列表页截图，或做一张纯色底+文字的图（900×383） |
| 原创声明 | 可开（自己的文字） |
| 留言 | 建议开启 |
| 赞赏 | 随意 |
| 标签 | 继续教育、效率工具、资产评估 |
| 定时群发 | 建议早上 8-9 点或晚上 8-9 点 |

## 七、如果不想发公众号

**只发朋友圈/群**，用这段短的就行（配 1 张图）：

```
花了 60 小时盯继续教育视频，实在受不了，抓包研究了下它的计时逻辑。

结论：学时按真实时间算，倍速完全无效（4 倍速播完，学时只走 1/4，还得补播）。

所以写了个脚本，只做一件事：学时满了自动换下一门，把"守着看"变成"挂着后台"。
不刷课、不改数据，就是省点注意力。

开源在这：github.com/zhuzhihaocool-bit/esnai-course-helper
```

## 八、几个注意点

**① 公众号正文不能放可点外链**

这是微信的硬规则，所有外部链接（包括 GitHub）只能以纯文本呈现。所以：
- 正文里的 `github.com/...` 保持纯文本，**不要**加超链接（加了也不生效）
- 靠文末「阅读原文」跳转

**② 不要用"刷课""代学""破解"等词**

这类词容易触发审核，也可能让平台方注意到。本文已经全程规避。

**③ 提一句"不伪造学时"很重要**

不是免责，是实际上让读者理解这个工具的边界。也降低被判定为"作弊工具"的风险。

**④ 如果读者问"能不能加速"**

直接回"不能，平台按真实时间算"，并把倍速表格发给他。这是这个平台最反直觉的地方，也是文章最有价值的信息。
