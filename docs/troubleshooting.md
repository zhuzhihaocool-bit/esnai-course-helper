# 常见问题排查

## 横幅没出现

**检查项**

1. Tampermonkey 是否启用（图标是否有数字角标）
2. 管理面板里脚本是否是**启用**状态
3. 地址是否匹配 `https://ce.esnai.net/*`（注意必须是 `https`）
4. 是否装了**多个副本**（重复脚本会互相顶掉，只保留一个）
5. 强刷页面：`Ctrl + F5`

---

## 显示"没扫到课程表格"

脚本等了 30 秒仍未在页面上找到含 `%` 的表格行。

**可能原因**

- 课程表格在**跨域 iframe** 里（脚本读不到）
- 登录已过期，页面跳到了登录页
- 平台改版，表格结构变了

**排查**：按 `F12` → Console 执行

```js
document.querySelectorAll('tr').length
// 以及
[...document.querySelectorAll('tr')].filter(tr => /\d+%/.test(tr.textContent)).length
```

如果第二条是 0，说明页面上确实没有百分比表格，属于平台结构问题，需要改解析逻辑。

---

## 列表页不自动刷新

**看横幅的倒计时**：

- 有 `⟳ 43 秒后刷新此页` 且在递减 → 正常
- 完全没有这行 → 脚本没加载（回到第一条）
- 倒计时不动 → 页面可能被浏览器"冻结"了（后台标签做了节能），点一下标签页激活它

**改间隔**：

```js
localStorage.setItem('sh-refresh', '120')   // 秒，最小 15
```

---

## 视频播完了但没跳下一门

**这是设计行为，不是 bug。**

脚本会用**列表页百分比**判断是否完成。如果列表页还是 30%，说明学时没记满，此时跳走会导致**这门课的学时永久丢失**。

横幅会提示：

```
视频播完了，但列表页只记到 30%　让本页继续开着累计学时　[仍然跳下一门]
```

**正确做法**：让这个标签继续开着（哪怕视频已结束），学时按真实时间累计。等列表页刷到 100%，它会自动跳。

**已知现象**：这种情况通常发生在你开过倍速。见 [how-timing-works.md](how-timing-works.md)。

---

## 新标签被浏览器拦截

Chrome 会拦截"无用户手势"的 `window.open`。

**表现**：没有新标签打开，但出现提示"浏览器拦了新标签　点这里打开"

**解决**：

1. 点提示里的链接（有点击手势，一定能开）
2. 或永久允许：`chrome://settings/content/popup` → 允许 → 添加 `https://ce.esnai.net`

---

## 新标签打开了但视频不播放

脚本每秒尝试一次 `play()`，最多 30 次。若被自动播放策略拦截，屏幕中央会出现：

```
▶ 点这里开始播放
```

点一下即可。

**注意**：脚本**不会**通过静音来绕过自动播放策略——那需要改 `muted`，已被证明会导致部分播放器黑屏。

---

## 播放标签关不掉 / 变成空白页

浏览器安全策略：**只有脚本自己 `window.open` 打开的标签才能被 `window.close()` 关闭**。

- 脚本自动打开的标签 → 能关
- 你手动粘贴地址打开的标签 → 只能变 `about:blank`

**这是浏览器的限制，无法绕过。** 空白页不占资源，不影响使用。

---

## 面板显示"列表页未开"

播放页的百分比来自**列表页缓存**。列表页关掉后就没有数据来源了。

**解决**：把 `study.do` 列表页开着（可以放后台），它会自己刷新。

---

## 视频画面全黑，但时间在走

**这不是本脚本导致的**（v1.7 起已移除所有破坏性操作）。

如果出现，按顺序排查：

1. **禁用 Tampermonkey**，刷新页面 → 还黑说明与脚本无关
2. 检查网络是否能访问 `v.qidian.qq.com`（腾讯点播埋点）
3. 换一门课试试（个别课程源文件可能有问题）
4. 清理浏览器缓存后重试

如果你确认是脚本导致的，请提 Issue 并附上：

- 脚本版本（面板上显示）
- 浏览器版本
- Console 里的报错

---

## 学时被回扣了（比如 232 → 229 分钟）

这是**服务端行为**，脚本无法干预。可能原因：

- 使用过倍速
- 跳转过进度
- 长时间切到后台
- 多设备同时登录

建议全程 1x、保持页面活跃。

---

## 完全重置脚本

在继续教育站点 Console 执行：

```js
['sh-auto','sh-courses','sh-done','sh-arrive','sh-rate',
 'sh-refresh','sh-active-player'].forEach(k => localStorage.removeItem(k));
['sh-refresh-count','sh-refresh-at'].forEach(k => sessionStorage.removeItem(k));
location.reload();
```

只清理脚本自己的键，**不会影响登录状态**。
